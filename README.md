# MyBigBazaar

A comprehensive multi-platform commerce and services ecosystem consisting of:

- **[admin](./admin)**: Admin portal built with React, Vite, and Tailwind CSS.
- **[api](./api)**: Node.js & Express REST API backend with database models, controllers, and services.
- **[mobile](./mobile)**: Mobile application built with React Native and Expo.
- **[web](./web)**: Customer-facing web portal built with React and Vite.

## Project Structure

```text
├── admin/       # Admin dashboard web app
├── api/         # Backend REST API
├── mobile/      # React Native / Expo mobile app
├── web/         # Customer web frontend
└── .gitignore   # Root Git ignore rules
```

## Getting Started

Refer to each directory's documentation and `package.json` for installation and running scripts.
Make sure to copy the corresponding `.env.example` files to `.env` in each respective folder before starting the services.
